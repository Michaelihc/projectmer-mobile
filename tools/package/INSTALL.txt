ProjectMER-Mobile {{VERSION}} for the Carl Mod SCP: Secret Laboratory server
===========================================================================

ProjectMER (MapEditorReborn, LabAPI edition) ported to LabAPI-Mobile. It runs
on the server only: players keep the stock Carl Mod Android client.
Built from commit {{COMMIT}}.

Requirements
------------
A Carl Mod server: 0.0.5, the official 0.0.4 server distribution or the
0.0.4 build with the deathmatch module, with LabAPI-Mobile installed:
https://github.com/Michaelihc/labapimobile

Carl Mod 0.0.5 needs LabAPI-Mobile 1.1.7-mobile.5 or later; earlier releases
do not run on 0.0.5. Use 1.1.7-mobile.5 or later on 0.0.4 too (tested on both
0.0.4 builds). Players need the Android client of the server's game version:
the 0.0.4 client cannot join a 0.0.5 server.

Install
-------
1. Install LabAPI-Mobile and start the server once, so its data folder
   <AppData>\SCP Secret Laboratory\LabAPI-Mobile\ exists. <AppData> is
   %APPDATA% of the user running the server, or the server's own AppData
   folder when hoster_policy.txt contains "gamedir_for_configs: true".
2. Stop the server and copy plugins\ProjectMER.dll from this archive into

     <AppData>\SCP Secret Laboratory\LabAPI-Mobile\plugins\global\

3. Start the server. The log shows ProjectMER being enabled. The first start
   creates
     LabAPI-Mobile\configs\ProjectMER\Maps         maps, <name>.yml
     LabAPI-Mobile\configs\ProjectMER\Schematics   schematics, <name>\<name>.json
4. Grant the commands in LabAPI-Mobile\configs\permissions.yml: "mpr.*" for a
   group, or "mpr.<command>" (for example mpr.load) per command.
5. Use "mp" in the Remote Admin console ("mp list", "mp load <map>"). In the
   server console and the phone's client console, type commands with a
   leading slash: /mp list

Phones render every networked object. Keep maps small: about 150 visible
primitives at a time is a good budget. "mp stats" shows the counts.

README.md (English) and README.zh-CN.md (Simplified Chinese) describe the
commands, the tool gun, the configuration and what content Carl Mod supports.
NOTICE.md lists the authors and the licence status.
